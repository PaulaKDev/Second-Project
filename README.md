# 🌍 Viajes Aventura

Plataforma web moderna para descubrir destinos únicos y planificar aventuras inolvidables.

## ✨ Características

- 🎨 Diseño moderno y responsive
- ♿ Cumple con estándares de accesibilidad W3C
- 🚀 Optimizado para rendimiento
- 📱 Compatible con dispositivos móviles
- 🎯 SEO optimizado

## 🛠️ Tecnologías

- **React 19** - Biblioteca de interfaz de usuario
- **Vite** - Herramienta de construcción rápida
- **ESLint** - Linter con reglas de accesibilidad
- **CSS3** - Estilos modernos con gradientes y animaciones

## 🚀 Instalación

```bash
# Instalar dependencias
npm install

# Instalar dependencias de accesibilidad
npm install --save-dev eslint-plugin-jsx-a11y

# Ejecutar en desarrollo
npm run dev

# Construir para producción
npm run build
```

## 📋 Scripts Disponibles

- `npm run dev` - Servidor de desarrollo
- `npm run build` - Construcción para producción
- `npm run lint` - Verificar código con ESLint
- `npm run preview` - Vista previa de la construcción

## ♿ Accesibilidad

Este proyecto cumple con las pautas WCAG 2.1 AA:

- Navegación por teclado
- Etiquetas ARIA apropiadas
- Contraste de colores adecuado
- Texto alternativo para elementos visuales
- Estructura semántica HTML5
